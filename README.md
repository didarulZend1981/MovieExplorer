#  Movie Explorer

A simple and responsive Movie Explorer application built with React, Vite, Tailwind CSS, React Router, and React Icons.

##  Features

-  Search shows by title
-  Browse shows
-  View show Modal
-  Responsive design
-  React Router navigation

## Technologies

- React
- Vite
- Tailwind CSS
- React Router
- React Icons
